# Token 節省與檔案操作原則 (嚴格執行)

1. 精確讀取：嚴禁全域搜尋或遍歷目錄。僅透過 `@檔案路徑` 讀取任務必要檔案。
2. 忽略目錄：嚴禁讀取 `.nuxt/`、`.output/`、`node_modules/`、`dist/` 與 lock 檔。
3. 局部輸出：修改程式碼僅提供變更的函式或 Template 片段，避免完整印出未修改的程式碼。
4. 精簡指令：執行測試或 Build 時鎖定單一檔案，避免 Terminal 大量 Log 塞滿上下文。
5. 避免重複讀取：不要重複讀取已經在上下文中的檔案。
6. 歷史壓縮意識：當發現對話歷史過長時，在回覆末尾請主動精簡當前上下文結論，只保留下一步所需的核心狀態。
