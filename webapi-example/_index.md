## 3. 查閱與開發原則

- **OpenAPI (Swagger) 規格**：為了讓 AI（特別是 `@plan-maker`）精準掌握 API 的輸入與輸出，每個 API 專案都強烈建議配有一份 `.json` 或 `.yaml` 的 Swagger 檔。
- **檔案放置規則**：未來建立新專案時，請將 Swagger 檔放置於專案自己的目錄內（例如 `{新專案名稱}/webapi/swagger.json`），並於本文件的「實際專案清單」中登記。
- AI 在處理後端開發或前後端串接任務時，會依據本文件登記的路徑，自動去抓取對應的 Swagger 檔案來解析 Request / Response 格式與欄位型別。
